# Keep companion memory consensual and user-controlled

Long-term memory is off until explicit opt-in. Stable low-sensitivity preferences and routines may then be saved automatically with a reversible receipt; health, bereavement, trauma, address, finance, and family-conflict memories require per-item confirmation. The user can view, edit, delete, or reset remembered content and the Companion Profile. That profile is limited to useful interaction preferences such as address, length, question style, topics, humor, advice preference, boundaries, and familiarity—never diagnosis, personality labels, disease, economic status, or family conclusions. Explicit preferences apply immediately; inferred updates run after the reply, use only the user's original words as evidence, require repeated support, and let low confidence affect only reversible expression. External enterprise profile data requires informed import and must remain visible and correctable. Runtime context combines recent raw turns, older fragment summaries, and relevant confirmed memories; emotion and intent remain transient dialogue state. Raw transcripts are retained for 90 days, and deleting source messages removes or rebuilds dependent candidates, evidence, and summaries while separately offering deletion of confirmed memories.
