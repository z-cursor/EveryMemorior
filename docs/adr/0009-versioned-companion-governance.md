# Govern companion behavior through immutable assigned versions

Each participant is pinned to one immutable Companion Config Version; existing relationships do not change until an explicit migration. The version includes the default FY-Qwen3.8-27B-NVFP4 model, thinking policy, generation parameters, one controlled Markdown behavior document, and its evaluation evidence. Ordinary members cannot select models, thinking levels, temperature, tools, or prompts. Owner and Admin roles use an administrator-only Companion Config page inside the existing settings UI to edit drafts, inspect diffs, run checks and evaluations, publish, assign, and migrate versions; Member users only manage their own profile, memory, privacy, and display. All administrative changes are audited, and the platform-owned baseline remains outside editable tenant behavior.
