Pi Web 视觉系统

面向高密度、长时间使用的 AI 编程工作台：内容优先、面板克制、状态清晰。数据来自 app/globals.css、app/settings.css、核心 React 组件内联样式与布局常量。

预览主题
01 / Principles

视觉层级与设计性格

1

对话是主舞台

主内容使用纯背景与最大空间；导航、文件树、工具状态退到灰色面板和较小字号。

2

层级来自明度

bg → bg-panel → hover → selected 形成四级表面，不依赖强阴影或厚重卡片。

3

强调色是稀缺资源

蓝色或主题强调色仅用于链接、焦点、活动状态、主要动作和实时状态。

4

高密度但不拥挤

控制项以 30–36px 为主，正文以 14px 为主；信息组之间用 12–24px 拉开。

5

边界代替装饰

大部分区域依靠 1px 语义边框分隔；阴影只属于浮层、输入框和临时覆盖面。

6

代码语境明确

路径、模型、状态、命令和代码使用等宽字体；普通说明保持系统无衬线字体。

边界优先级

  1. 永久布局分区：1px 边框，不用阴影。
  2. 列表选中：--bg-selected，必要时加字重。
  3. 焦点：2px --accent outline，避免仅靠颜色。
  4. 代码块：7px 圆角 + 1px 边框 + 极轻底边阴影。
  5. 遮罩：Modal 使用黑色 35–38%；图片预览使用 72%。

08 / States & Motion

交互状态、图标与动效

状态阶梯

  1. Default：透明或 --bg。
  2. Hover：--bg-hover，文字转 --text。
  3. Selected：--bg-selected + 600 字重。
  4. Focus：2px accent outline，offset -2 或 +2。
  5. Disabled：opacity 0.38–0.55，禁用 pointer。
  6. Loading：维持布局，不让控件跳动。

时间与运动

  • 颜色/背景反馈：100–150ms。
  • 面板开合：200–250ms ease。
  • 长反馈动画：保存成功、更新脉冲才使用。
  • Chevron 旋转：150ms。
  • 避免装饰性连续动画；运动要说明状态变化。

图标

常规图标 11–16px；文件图标 14px；空状态插图 32–44px；顶栏命中区 36px；移动触控命中区至少 44px。图标默认继承 currentColor，文件图标通过 mask 收敛为 --text-dim。

滚动条

全局 WebKit 滚动条宽/高 4px；thumb 为 --border，hover 为 --text-dim，圆角 2px。需要稳定布局的日志区使用 scrollbar-gutter: stable。

10 / Rewrite Contract

后续 UI 改写的统一约束

✓ 应该保持

  • 对话列始终是页面最高视觉优先级。
  • 组件只消费语义颜色，不写主题分支。
  • 主体 14px、控制 12px、元数据 11px。
  • 30–36px 桌面密度，44px 移动触控目标。
  • 永久区域用边框，浮层才使用阴影。
  • 路径/命令/模型/Token 使用等宽字体。

× 应该收敛

  • 不要继续新增散落的十六进制状态色。
  • 不要为同类按钮创造新的高度与圆角。
  • 不要把 hover 色当 selected 色。
  • 不要用大面积 accent 抢走对话注意力。
  • 不要在 React 内联样式中复制基础 token。
  • 不要让“全局”同时表示用户、租户和宿主机。

改写验收清单

  • 五套主题都能读清正文、弱文案、边框和焦点。
  • 同类控制项只使用既定字号、高度、圆角和间距。
  • 对话最大宽度、侧栏和右面板尺寸由统一变量控制。
  • 桌面 960px 以上三栏不挤压聊天到 420px 以下。
  • 移动端设置、侧栏、文件面板和输入框逐项验证。
  • 新状态色先加入 token，再被组件消费。
  • 保留 reduced-motion、键盘焦点和触控命中区。

迁移边界：通用字号、间距、圆角、边框、动效和状态色已经迁移为 Token；业务宽高、定位坐标、图表色阶及 xterm ANSI 调色板仍保留原值。后续新增 UI 应优先消费语义 Token，不要重新引入同类字面量。
