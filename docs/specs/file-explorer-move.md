# 文件区批量操作与指定目录上传

状态：产品需求与测试边界均已由用户确认；规格已发布，可供实现。尚未实施。

正式 tracker：[GitHub Issue #6](https://github.com/z-cursor/EveryMemorior/issues/6)。

标签状态：ready-for-agent 已通过登录为 z-cursor 的 GitHub CLI 添加并验证。

## Problem Statement

当前 Workspace 的文件区可以浏览、预览、引用、上传和单项删除文件，但无法通过拖动或按钮将已有文件整理到指定文件夹，也缺少统一的批量选择能力。上传按钮和从电脑拖入文件均使用文件区根目录，展开子目录不会改变上传目标。

用户需要在文件区完成日常整理：一次选中多个文件或文件夹，移动到明确的位置、引用到当前聊天或批量删除，并能直接向指定目录上传内容。操作过程中必须看清目标，理解重名、取消、部分失败及撤销的实际结果。

## Solution

为当前 Workspace 的文件区提供统一勾选和批量操作栏，包含“引用到聊天”“移动到…”和“删除”。保留普通点击文件打开预览的行为。

移动同时支持内部拖动和文件夹选择窗口。目标目录在松手或提交前明确展示，支持新建目录；文件夹与其内容整体移动。移动无冲突时立即执行，有冲突时由用户选择自动改名、跳过或取消。提供当前页面内最近一次移动的撤销。

上传按钮先选择平台目录，再选择电脑中的内容；外部文件可直接拖到文件夹行上传。上传文件夹保留目录结构，允许明确选择替换普通文件，并提供自动改名保留两者。

批量引用只加入聊天输入框。删除必须统一确认并提示无法撤销。全部操作保持 Tenant Membership 与 Workspace 的服务端授权边界。

## Implementation Decisions

### 文件操作与访问边界

- 文件区仍基于 Workspace 的真实目录树和路径；本功能不引入文件资料库或永久文件身份系统，不改变 Agent session 生命周期。
- 扩展现有文件 API 的操作能力，提供目录创建、移动、撤销所需的服务端操作，并扩展上传冲突处理；保留现有浏览、预览、监听、下载及删除能力。
- 操作输入表达当前 Workspace、来源项、目标目录和冲突策略。批量结果逐项表达成功、跳过、失败、需用户处理的冲突及尚未处理项；成功移动返回实际来源和目标路径，用于预览更新及撤销。
- 目录创建输入为授权父目录及单个目录名称。服务端拒绝无效名称、路径穿越及同名条目，不静默复用已有同名目标。
- 每次读取、冲突检查及执行均在服务端验证 Tenant Membership 和当前 Workspace。来源与目标必须属于同一当前授权 Workspace，不能仅检查全局允许根目录。
- 复用已有统一路径与授权边界，处理真实路径、符号链接、共享路径比较和平台客户端路径转换，拒绝越界、根目录破坏及已有受保护目录操作。浏览器输入不扩大权限，错误与结果不泄露宿主物理路径。
- 预检查不保证目标在执行时保持不变；执行时重新检查权限、来源、目标和同名冲突。路径被替换或目标不再可用时返回可解释结果，不按过时检查覆盖内容。
- 本功能不更改数据库 schema、Tenant、Workspace 或 Agent Session Binding 的归属模型。

### 选择与目标交互

- 三种批量操作共用选择状态；支持勾选、Shift 连选、Ctrl／⌘ 多选、全选当前可见条目及清空。Shift 按当前可见顺序连选；切换搜索条件清空选择。
- 折叠目录中的子项不因全选而额外勾选；选择目录意味着移动或删除整个目录。移动与删除将父子重叠选择归一到最上层项，引用仅去除重复路径，保留明确选中的父子项。
- 内部拖动与外部文件上传使用可区分的数据类型与提示，外部上传不得被误识别为移动。内部移动只接受目录行和根目录入口；外部上传额外接受明确提示根目录的空白区域，普通文件行不可放置。
- 拖动提交以松手时有效高亮目标为准，不通过缩进或附近位置猜测。折叠目录悬停约 700 毫秒展开，边缘滚动；取消或结束拖动后清理提示及计时状态。
- “移动到…”和上传目标选择共用文件夹浏览与新建能力；只展示当前 Workspace 内可访问目录，展示完整客户端目标路径。
- 目标选择界面提前禁止自身及后代目标；服务端仍独立校验。批量中已在目标目录的项跳过，其他有效项继续。
- 手机使用勾选、目标选择和按钮完成操作；沿用现有翻译和组件风格，操作控件提供可访问名称。

### 批量移动、冲突和取消

- 无冲突时立即移动；内容保持不变，原路径不保留副本。保留原名称，只有用户选择自动改名时改变名称。
- 移动冲突只允许自动改名、跳过、取消。普通文件按扩展名前递增后缀改名，例如照片.jpg → 照片 (1).jpg；目录在完整名称后加后缀。同一批次的新目标名称必须互不冲突。
- 不覆盖或合并目录；目录整体移动或整体改名。工作区根目录本身不作为可移动条目。
- 冲突界面提供对剩余冲突应用相同选择。批量执行保持可暂停边界，取消停止尚未执行的项，已完成项保留；不把取消表述为自动回滚。
- 部分失败允许其他项继续。结果数量基于归一后的实际处理项，同时列出成功实际路径、跳过原因、失败原因及取消后尚未执行项。
- 成功后刷新相关目录，展开目标、滚动定位并短暂高亮成功项；清除成功项选择，保留失败和跳过项选择。不要在服务端确认成功前伪造移动结果。

### 撤销与预览引用

- 最近一次移动的撤销记录仅在当前页面及当前 Workspace 上下文中有效，包含成功项的实际路径映射。部分成功批次和取消前已成功项也可撤销。
- 撤销是对成功移动项的反向操作，使用同一授权、冲突和结果能力。原位置后来有同名条目时，可自动改名恢复、跳过或取消剩余撤销；默认不覆盖。
- 已删除、再次移动或无法确认仍是该移动对象的项不得误恢复其他内容，逐项说明无法撤销原因；撤销允许部分成功。
- 预览管理根据服务端成功路径映射更新打开文件；目录移动同时映射其后代路径。撤销使用实际恢复路径，自动改名恢复时同样跟随。
- 历史聊天消息与 session 原始引用不改写，不建立永久路径重定向；原路径无法读取时展示用户确认的失效提示。

### 上传与删除引用

- 上传文件、上传文件夹先选平台目标，再打开本地选择窗口；默认根目录，可新建目标目录。取消任一步不提交上传。
- 一次上传固定使用已选择的目标目录，冲突选择与执行不得因目录树展开或 Workspace 切换而悄然改写目标。请求执行重新授权，继续沿用已有请求体与文件大小限制。
- 上传扩展自动改名策略，保留明确选择的普通文件替换、跳过和取消，默认不覆盖。替换不适用于目录及符号链接；不合并同名目录。
- 文件夹上传以顶层文件夹为一个整体决定重名处理，保留内部相对路径。自动改名时整个目录使用同一个新顶层名称，不逐个打散内部文件。
- 保留现有上传反馈能力，并按实际目标目录及实际改名结果定位文件和生成引用。
- 批量引用只修改当前聊天草稿，插入客户端可用路径，不自动发送消息，不触发 AgentSession 创建或恢复，引用后保留选择。
- 批量删除复用服务端删除语义与保护边界。一次确认列出归一后的条目并明确递归删除、无法撤销；失败不阻止其他项，清除成功项选择并保留失败项。
- 上传与删除均不提供本功能的撤销；不把删除按钮描述为可恢复操作。

## Testing Decisions

状态：用户已确认采用文件 API＋真实文件系统＋浏览器交互这组测试边界。

基线验证：2026-10-09 已运行现有相关测试，共 55 项通过、0 失败、0 跳过，涵盖文件 API、上传冲突、符号链接越界、成员隔离、路径转换、预览状态及历史引用。测试分组串行运行以避免共享状态污染。结果只证明现有边界可复用，不代表尚未实现的移动、撤销及批量交互已通过验收。现有浏览器套件未覆盖本规格的新交互，相关用例须在实现时补齐。

### 主要边界：文件 API 与真实文件系统结果

优先从现有文件 API 测试边界驱动开发，用真实临时 Workspace、隔离 Tenant Membership 和文件目录调用请求入口。断言响应、实际内容、来源是否存在、目标名称、目录结构及越界操作无副作用，不依赖内部函数调用次序。

现有先例包括文件与目录删除及根目录保护的路由测试、文件夹上传相对路径测试、上传冲突与符号链接保护测试，以及成员工作区授权和路径访问测试。涉及共享全局状态和数据库的夹具必须按现有隔离与清理约定组织，避免并行污染。

覆盖：

- 单文件、多文件、目录和混合批次移动；来源消失、目标内容不变。
- 同时选中父子项归一、同目录跳过、自身及后代拒绝。
- 移动与撤销自动改名、连续重名、同批次名称碰撞、跳过及取消后保留已完成项。
- 部分失败、目标被删除或替换、冲突检查后的并发变化，以及执行时重新授权。
- 最近移动撤销、原位置出现新同名项、部分撤销成功、来源已删除或再次移动及替换对象拒绝。
- 指定根目录、嵌套目录和新建目录上传；文件夹整体改名及结构保持；明确替换普通文件、目录和符号链接不可替换。
- 未登录、跨 Membership、跨 Workspace、路径穿越、符号链接越界、根目录与受保护条目均被拒绝且无文件变化。
- 新建目录的合法名称、无效名称、同名及授权失败。
- 批量删除递归语义、父子归一和部分失败。
- 返回结果使用授权客户端路径，上传大小限制继续生效。

### 用户交互边界：浏览器可见行为

沿用项目已有的 Playwright 浏览器回归运行器，以隔离临时文件夹与认证夹具覆盖完整操作。无需模型凭据，不调用真实 Agent。

覆盖：

- 勾选、快捷多选、可见范围全选、搜索切换清空；点击文件预览。
- 内部拖动有效目录与根目录、无效落点、目标提示、悬停展开、边缘滚动、Esc 取消。
- 拖动选中与未选中条目的不同范围，按钮目标选择、新建目录与手机操作。
- 冲突选项、应用到剩余项、取消提示、实际数量、结果定位与选择状态。
- 外部拖入与内部移动不混淆；上传按钮选择顺序、目标固定、空白处根目录提示。
- 批量引用只加入草稿、不发送；文件夹和明确选中的子文件路径均保留。
- 删除统一确认及不可撤销提示，取消确认不修改文件。
- 移动与撤销后的预览跟随、历史原文保持、失效引用提示。

现有文件预览页签状态和路径引用测试可补充直接的状态行为回归。仅当真实边界难以稳定触发命名竞争或路径映射边界时，补充最少的纯函数测试；避免新增跨层 mock 或复制实现的测试。

实现阶段按 TDD 逐个行为推进，定期运行相关测试与类型检查，最终运行 lint、TypeScript、完整单元测试及相关浏览器回归。遵循仓库约定，开发期间不运行完整构建。当前规格编写阶段不执行尚不存在的功能测试。

## Out of Scope

- 跨 Workspace 或跨 Tenant 的文件移动、复制，以及工作区根目录本身的移动或删除。
- 移动覆盖、同名目录合并、上传目录整体替换或合并。
- 回收站、删除恢复、上传撤销、多步或跨刷新持久撤销历史。
- 永久文件 ID、历史聊天引用自动改写或持久路径重定向。
- 独立重命名功能、复制粘贴、剪切板操作及文件夹下载。
- 修改 Agent 生命周期、Skill Runtime Protocol 或传记产物生成协议。
- 绕过已有权限、隐藏目录保护和上传大小限制。
- 当前浏览器文件选择不能表达的空目录上传能力；不承诺未提交的空目录会被创建。
